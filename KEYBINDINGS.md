# WezTerm Key Bindings

## Leader

`CTRL+A` activates the leader. Bindings below marked **Leader** are pressed after it.

## Panes

| Binding | Action |
|---|---|
| `ALT+H/J/K/L` | Move focus left/down/up/right |
| `SHIFT+ALT+Left/Down/Up/Right` | Resize pane |
| `ALT+\` | Split pane horizontally |
| `ALT+-` | Split pane vertically |
| `ALT+W` | Close pane |
| `ALT+P` | Open pane swap picker |
| `ALT+F` | Toggle pane focus (zoom) |

## Tabs

| Binding | Action |
|---|---|
| `CTRL+SHIFT+T` | New tab |
| `CTRL+SHIFT+W` | Close tab |
| `CTRL+SHIFT+H` | Previous tab |
| `CTRL+SHIFT+L` | Next tab |
| `CTRL+SHIFT+Left` | Move tab left |
| `CTRL+SHIFT+Right` | Move tab right |
| `CTRL+SHIFT+1–9` | Jump to tab N |

## Workspaces & Launcher

| Binding | Action |
|---|---|
| **Leader** `W` | Show workspace switcher |
| **Leader** `SHIFT+W` | Create new workspace |
| **Leader** `Space` | Show full launcher |

## Clipboard

| Binding | Action |
|---|---|
| `CTRL+V` | Paste via clipboard bridge |
